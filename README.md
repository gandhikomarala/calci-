# Calci Studio — Scientific & Mortgage Amortization Suite

Dual-engine financial and scientific computation platform with RPN math evaluation, mortgage amortization schedules, compounding interest graphs, currency converter, and calculation tape export.

## Product Highlights
- **Domain**: FinTech / Utilities
- **Visual Theme**: Brushed Titanium & Amber Quartz
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
