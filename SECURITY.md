# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting Vulnerabilities
Please report security concerns directly to the maintainer via secure channel. Do not disclose security vulnerabilities in public GitHub issues.

### Response SLA
- **Initial Acknowledgment**: < 24 hours
- **Triage & Reproduction**: < 72 hours
- **Hotfix Release**: < 7 days
